I used SWI-Prolog.
the LLM I used for this assignment was Microsoft Copilot.
you can download SWI-Prolog from its website under the 'download' tab; go to 'SWI-Prolog' > 'development release' > download according to laptop model. 
 
Create a .txt file and paste the following information below 

decay(K, T, Y) :-
    Y is exp(-K * T).

plot_2d(K) :-
    MaxY = 10,

    % Draw graph from top to bottom
    forall(
        between(0, MaxY, Row0),
        (
            Row is MaxY - Row0,
            Label is Row / 10,
            format('~1f |', [Label]),

            forall(
                between(0, 15, T),
                (
                    decay(K, T, Y),
                    Pos is round(Y * 10),
                    (Pos =:= Row -> write('*')
                    ; write(' '))
                )
            ),
            nl
        )
    ),

    write('    +---------------'), nl,
    write('     0123456789012345'), nl.


you will save this as decay.pl under the Prolog section in your saved folders .
you will open this in Prolog: 
['C:/Users/YourName/Documents/Prolog/decay.pl']. 
you will see: true. in response 

run the graph: 
?- plot_2d(0.3).

SWI-Prolog does not function in the same way Python or R does; I could not graph a neat, tidy graph about exponential decay on it 
because it primarily works as logic programming and uses English text. You would otherwise need an external program. It is good for 
complex rules, logic and reasoning problems, but is probably not great for things like this -- Python or R would be preferable. This was 
the closest I could personally get to coding exponential decay.
