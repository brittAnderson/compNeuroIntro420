*** MESA
  
**** Steps to begin[fn:2]
1. Set up a python virtual environment. I have been using the tool =uv=[fn:1].
2. In a directory where you want to work,

   #+begin_src sh :eval never
     uv venv 
   #+end_src

   This will create a hidden subdirectory called ~.venv~. Inside there is where your python libraries will be stored.
3. Activate the virtual environment.

   =source ./.venv/bin/activate=
4. Get the necessary libraries

   #+begin_src sh :eval never
     uv pip install mesa
   #+end_src

   Repeat for =jupyter= and =seaborn=
5. Next start a jupyter instance with =jupyter lab=.


**** Testing
